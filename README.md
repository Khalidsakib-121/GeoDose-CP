# GeoDose-CP

Publication code, frozen configuration material, compact data provenance, and reproducibility authorities for **GeoDose-CP: Graph-Local Conformal Inference for Continuous-Treatment Earth Observation**.

## Repository layout

- `code/` — stage-by-stage implementation from Stage1 through Stage6A.
- `code/14_stage5a_external_context/` — accepted external-context production code and frozen provenance outputs.
- `code/14b_stage5a_minedosebench_publication_core/` — hash-verified MineDoseBench scientific core plus accepted v1.2 release metadata/audits.
- `code/15_stage5b_minedosebench_evaluation/` — frozen Stage5B evaluation implementation.
- `code/17_stage6a_nsw_real/` — real NSW predictive/refusal evaluation.
- `data/` — compact source registry and exact frozen acquisition records; large third-party source datasets are not duplicated.
- `provenance/` — source/archive identities, accepted authorities, and web/source records.
- `docs/` — data/claim boundaries and redistribution notes.
- `paper/` — manuscript-ready Code and Data Availability template.

## Scientific boundaries

MineDoseBench is semi-synthetic: it retains real NSW geometry/graph/EO/context while treatment assignment and potential-outcome truth are generated by the benchmark DGP. The real NSW study does **not** construct an annual rehabilitation treatment from the public snapshot; treatment-dependent M2/M4/M6 are therefore nonoperational there, while treatment-free predictive procedures are evaluated separately.

The accepted MineDoseBench v1.2 benchmark release is the authority consumed by Stage5B. The publication package preserves byte-matched scientific modules and the v1.2 release metadata/audits rather than presenting the obsolete unchanged v1.1 freeze as the final benchmark.

## Data

Original third-party NSW, Digital Earth Australia, SILO, TERN, and Geoscience Australia source datasets are not duplicated here. `data/` and `provenance/` provide provider links, product identifiers, exact frozen acquisition records, and processing provenance.
