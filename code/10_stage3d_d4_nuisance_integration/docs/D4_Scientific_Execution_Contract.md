# D4 Scientific Execution Contract

## Gate question

Can the frozen exact GeoDose-CP source implementation evaluate new small Stage 3B cases while treatment-law and graph-law nuisance sources are varied, without changing the accepted G1/G2/G3 mathematics or the accepted M3/M4 definitions?

## Required answer

D4 passes only if all of the following are true:

1. Accepted upstream hashes and source trees are unchanged.
2. The complete D2 source tree matches the accepted 41-file inventory and the exact accepted D2 API lock (call signatures, frozen tolerances, and tie-randomization contract) passes before source replay or new-data evaluation.
3. The accepted D2 source-level evaluator reproduces archived D2 conservative and randomized p-values, tie uniform, acceptance decisions, and quotient-state counts before any new-data evaluation, including the accepted duplicate-payload quotient fixture.
4. M3 remains treatment-transport free and is numerically invariant to OT versus ET at fixed graph/candidate.
5. M4 remains exactly one normalization of the accepted M2 dose ratio times accepted M3 spatial source marginal.
6. M6 comes from the accepted D2 CandidateEvaluator and not from a new implementation of G1/G2/G3.
7. New exact cases S2/S3/S4/S6/S7/ST1 execute for their registered nuisance variants on a fixed diagnostic candidate grid; scenario labels alone are not used to force numerical method equalities.
8. Endpoint target doses remain exact atoms; no jitter, clipping or smoothing is introduced. An unaudited endpoint and a disconnected exact block are both required to fail closed in explicit D4 refusal smoke tests.
9. Fitted graph cases use accepted Stage 3B fitted edges and recomputed graph degrees; rho and scale stay oracle in D4.
10. Accepted D3 factorization/nonfactorization and reduction gates remain unchanged.
11. The D4 target slot is frozen to node 320 (not selected by role alone), and all registered D4 exact-wiring cases must pass the observed-versus-true outcome alignment gate.
12. No repeated-coverage, pilot, production, scalable-certification or publication-performance claim is made.

## Why D4 precedes Stage 3E

D4 isolates correctness of exact source-level plumbing. Stage 3E is a separate scientific task: it replaces infeasible exact enumeration at realistic scale with N2/N3 approximation/certification and refusal logic. Combining these two gates would make failures difficult to diagnose and would blur the exact-versus-scalable claim boundary.
