# Stage6A Real NSW Demonstration — Claim Boundary

This stage is an applied **observed satellite-product uncertainty demonstration**, not a causal validation experiment.

Frozen Stage1 established that an annual longitudinal rehabilitation implementation dose cannot be constructed from the public NSW snapshot. Therefore:
- `mapped_rehabilitation_fraction` is **not** treated as a continuous intervention;
- it is **not** used as a predictor because it is snapshot context dated after the 2024→2025 outcome window;
- no annual treatment `A_it` is invented;
- M2, M4 and M6 treatment-dependent real-data routes return `R20_NO_AUTHENTIC_LONGITUDINAL_TREATMENT`;
- M4's unit-treatment-ratio reduction to M3 is audited only as an algebraic reduction;
- real interval coverage is held-out coverage for the observed DEA PV-change product and is not potential-outcome coverage.

Causal validity evidence remains the frozen controlled simulation and MineDoseBench evidence. The NSW real stage demonstrates spatial splitting, support/refusal behavior, product-quality sensitivity, MAUP, leakage diagnostics, uncertainty/warning mapping and practical reproducibility.

Bare-ground change is not fabricated because the frozen Stage2B production contains PV and UE only.
