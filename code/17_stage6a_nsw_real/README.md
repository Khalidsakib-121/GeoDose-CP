# GeoDose-CP Stage6A — Real NSW Demonstration v1.0.0

This is the final applied NSW production stage after the frozen Stage5B MineDoseBench evaluation.

## What it does
- verifies exact frozen Stage1/Stage2A/Stage2B/context/Stage3F authorities;
- reconstructs the prespecified three-mine 90 m real substrate;
- creates the anchored 180 m MAUP sensitivity;
- fits frozen RF and XGBoost predictors using 2023/2024 pretreatment information only;
- evaluates operational real-data M1, M3 and M5 uncertainty;
- explicitly refuses M2/M4/M6 because Stage1 found no authentic longitudinal continuous rehabilitation treatment;
- produces leakage, product-quality, MAUP and support diagnostics;
- writes seven publication-grade figure pairs;
- is resumable across 12 atomic mine × scale × predictor tasks.

## Claim boundary
Real coverage is held-out coverage of the observed DEA fractional-cover-change product. It is not causal potential-outcome coverage. The snapshot mapped-rehabilitation fraction is descriptive only and is never a treatment or predictor.

Extract under a short path such as `D:\G6A` and double-click `RUN_NSW_REAL_DEMONSTRATION.bat`.

If interrupted, rerun the same BAT. Do not delete `_STAGE6A_WORK`.
