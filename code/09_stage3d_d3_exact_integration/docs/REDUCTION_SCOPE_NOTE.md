# R1–R4 scope note

The frozen Stage 3A registry assigns:
- R1 to Stage 3D;
- R2 to Stage 3C/Stage 3D;
- R3 to Stage 3E;
- R4 to Stage 3C.

Accordingly, this exact D3 package verifies R1, R2 and R4. R3 is reported as `DEFERRED_STAGE3E`, not failed and not falsely completed. R3 concerns the target-weighted N2 sparse-approximation criterion and can only be implemented honestly when N2 exists.
