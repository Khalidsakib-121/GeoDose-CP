# Exact integration scope

This gate establishes software identity and exact-reference interoperability only. It is not empirical coverage evidence.

The six-method common schema allows different valid output representations: M1/M2/M5 are frozen split/weighted interval procedures; M3/M4/M6 are candidate-inversion procedures on the exact D3 reference block. Successful computation does not imply equal theorem status.

The D2 M6 adapter refuses any candidate not already evaluated by accepted D2. This is deliberate fail-closed behavior. The next stage must construct a source-level M6 adapter from the verified local D2 source before pilot replications are permitted.
