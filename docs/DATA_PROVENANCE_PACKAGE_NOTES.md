# GeoDose-CP — Step 2: Compact Data and Provenance Package

This package is intended to accompany the **Step 1 audited code bundle** in a public GitHub repository. It is deliberately compact: it records authoritative source links, exact frozen external-context acquisition URLs, product/layer identifiers, provenance manifests, and redistribution/claim boundaries **without duplicating large third-party source datasets**.

## What is included

- `data/SOURCE_REGISTRY.csv` / `.json` — human- and machine-readable logical source registry for all external data families used in GeoDose-CP.
- `data/NSW_SOURCE_LAYERS.csv` — exact NSW ArcGIS layer identities used for Stage1 L03 rehabilitation and L04 disturbance.
- `data/EXACT_FROZEN_CONTEXT_SOURCE_ASSETS.csv` / `.json` — exact SILO, TERN, and Geoscience Australia acquisition/source rows extracted from the accepted Stage5A provenance authority.
- `data/SOURCE_CITATIONS.md` — source citations matching manuscript data references [45]–[55].
- `provenance/STAGE2B_DEA_SOURCE_CONTRACT.json` — exact DEA product/access contract extracted from the frozen Stage2B code.
- `provenance/STAGE5A_SOURCE_PROVENANCE_MANIFEST.json` — byte-for-byte copy of the accepted Stage5A final-context source provenance manifest.
- `provenance/STAGE5A_SOURCE_SUPPORT_CENSUS_MANIFEST.json` — byte-for-byte copy of the accepted Stage5A support-census source manifest.
- `provenance/WEB_VERIFICATION_RECORD.md` — current official landing/service pages checked when this package was assembled.
- `DATA_AND_CLAIM_BOUNDARY.md` — clear distinction between external source data, derived data, MineDoseBench synthetic truth, and the real NSW observed-product study.
- `paper/CODE_AND_DATA_AVAILABILITY_TEMPLATE.tex` — manuscript-ready template to fill after the GitHub URL is known.

## Important scope

This package **does not claim that the NSW rehabilitation snapshot is an authentic annual treatment history**. Stage1 established that the required longitudinal treatment is not constructible from the frozen public snapshot. In the real NSW stage, mapped rehabilitation is not used as treatment or as a predictor; treatment-dependent M2/M4/M6 remain nonoperational.

MineDoseBench is semi-synthetic: real NSW geometry/graph/EO/context are retained, while treatment assignment, potential outcomes, residual/measurement-error processes, and target truth are generated by the benchmark DGP.

## Raw-data redistribution

Large upstream source datasets are not copied into this compact package. The official source links and exact frozen acquisition records are provided so users can obtain the original data from the providers. This avoids pretending that third-party source bytes are authored by this project and keeps the GitHub repository manageable.

The audited Step 1 code bundle is `GeoDose_CP_GitHub_CODE_STEP1_AUDITED_v2.zip`. Its SHA-256 is recorded in `provenance/STEP1_CODE_PACKAGE_LINKAGE.md`.
