# Source licensing and redistribution notes

This file is a provenance aid, not legal advice. Users should follow the terms published by each data provider.

- **NSW Resources / Data.NSW:** the current dataset page identifies the Mine Rehabilitation Data resource as Creative Commons Attribution. This package links to the official dataset and layer services; raw polygons are not bundled here.
- **Digital Earth Australia:** the official Fractional Cover and Water Observations product pages identify the products as CC BY 4.0. Raw COG assets are not bundled here.
- **SILO:** the official SILO access/licensing page states that SILO products are available under CC BY 4.0. Original annual NetCDF files are not bundled here.
- **TERN Soil and Landscape Grid:** authoritative product DOI links are supplied. Exact TERN COG and metadata asset URLs are retained from the accepted frozen Stage5A provenance manifest. Users should consult the DOI/product page for current access and licensing terms.
- **Geoscience Australia SRTM-derived DEM:** the official product authority identifies CC BY 4.0. The national DEM is not bundled here.

Derived project tables can be released separately subject to the upstream attribution/redistribution obligations applicable to the incorporated source material.
